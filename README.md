# claude-mods

Eigene Mods für Claude Code, als Plugin-Marketplace.

```bash
claude plugin marketplace add tw67/claude-mods
```

| Plugin | Beschreibung |
| --- | --- |
| [abo-usage](abo-usage/) | Claude-Abo-Nutzung als farbige Balken mit Reset-Zeit und Higgsfield-Credits über dem Eingabefeld |

Installieren: `claude plugin install <plugin>@claude-mods`
